ระบบติดตั้งอัตโนมัติแบบ 1-Click สำหรับเครื่องใหม่ และการอัปเดตโค้ดอย่างปลอดภัย
กองกำกับการตำรวจตระเวนชายแดนที่ 21 (กก.ตชด.21) — กองร้อย ตชด.215 1-Click Automated
💡 จุดเด่นของระบบใหม่: ไม่ต้องพิมพ์คำสั่งใน Terminal เองแม้แต่บรรทัดเดียว! ระบบสร้างไฟล์ .env, สุ่มสร้างรหัสความปลอดภัย 64 หลัก, สร้างใบรับรอง SSL, เปิดบริการทั้งหมด และสร้างบัญชี admin ให้เสร็จสรรพในคลิกเดียว

🚀 ตอนที่ 1: ขั้นตอนการลงเครื่องใหม่ (3 สเต็ปง่ายที่สุด)

1

เปิดโปรแกรม Docker Desktop

เปิดโปรแกรม Docker Desktop บนหน้าจอ Windows ของท่าน รอจนกระทั่งสถานะที่มุมซ้ายล่างเปลี่ยนเป็นสีเขียว (Engine running)

2

นำโฟลเดอร์ระบบมาวางไว้ที่ D:\BPP-VMS (Zero-GitHub — ปลอดภัย 100%)

🛡️ หมดปัญหาเรื่องความเสี่ยง: ท่านไม่ต้องล็อกอินบัญชี GitHub และไม่ต้องพิมพ์ Personal Access Token (PAT) บนเครื่องใหม่ให้เสี่ยงต่อการถูกขโมย เลือกดาวน์โหลดหรือก๊อปปี้ได้ง่ายๆ ตามนี้:

📦 วิธีที่ 1 (สะดวกที่สุด): กดดาวน์โหลดไฟล์ ZIP ผ่านหน้าเว็บ

เปิดเบราว์เซอร์จากเครื่องใหม่ แล้วกดปุ่มดาวน์โหลดแพ็กเกจติดตั้งสำเร็จรูป:

ดาวน์โหลด bpp-vms-installer.zip

📍 หากเปิดไฟล์นี้บนเครื่องหลัก: ไฟล์นี้มีอยู่แล้วบนเครื่องของท่านที่ D:\BPP-VMS\bpp-vms-installer.zip ก๊อปปี้ใส่ Flash Drive ได้ทันที

🌐 ลิงก์ดาวน์โหลดโดยตรงสำหรับเครื่องใหม่: https://vms.local/downloads/bpp-vms-installer.zip

💾 วิธีที่ 2 (ออฟไลน์ 100%): ก๊อปปี้ผ่าน Flash Drive จากเครื่องแม่

ที่เครื่องแม่ ให้ดับเบิลคลิกไฟล์ Export_Installer_Package.bat ระบบจะสร้างไฟล์ bpp-vms-installer.zip ให้ทันทีใน 4 วินาที ➔ นำไฟล์ใส่ Flash Drive ไปเสียบเครื่องใหม่ แล้วแตกไฟล์ลงไดรฟ์ D:\

เมื่อแตกไฟล์เสร็จ โครงสร้างไดเรกทอรีที่ได้จะถูกต้องสมบูรณ์แบบตามคู่มือ 100%:

D:\BPP-VMS\
├── Setup_New_Machine.bat          <-- [ดับเบิลคลิกไฟล์นี้เพื่อเริ่มติดตั้ง]
├── Update_System.bat             <-- [ดับเบิลคลิกไฟล์นี้เมื่อต้องการอัปเดต]
├── Export_Installer_Package.bat  <-- [ส่งออกชุดติดตั้งสำหรับเครื่องอื่น]
├── Export_System.bat             <-- [ส่งออกข้อมูลจากเครื่องเก่า]
├── Import_System.bat             <-- [นำเข้าข้อมูลสู่เครื่องใหม่]
├── git_and_fresh_install_manual.html
└── frigate-nvr\
3

ดับเบิลคลิกไฟล์ Setup_New_Machine.bat

คลิกขวาที่ Setup_New_Machine.bat > เลือก Run as administrator (หรือดับเบิลคลิกปกติ)

  • ระบบจะสุ่มสร้างรหัสความปลอดภัย 64 หลักลงใน .env ให้อัตโนมัติ
  • ระบบจะสร้างใบรับรองความปลอดภัย HTTPS ให้อัตโนมัติ
  • ระบบจะเริ่มบริการคอนเทนเนอร์ Docker ทั้ง 17 ตัว
  • ตั้งรหัสผ่าน Admin: เมื่อระบบถามรหัสผ่าน ให้กดปุ่ม [Enter] ทันที เพื่อใช้รหัสเริ่มต้น ChangeMeAdmin123! (หรือพิมพ์รหัสผ่านที่ต้องการ)
  • ระบบจะเปิดเบราว์เซอร์เข้าสู่หน้าเว็บ https://localhost ให้ทันที!

* ข้อมูลชื่อผู้ใช้และรหัสผ่านจะถูกบันทึกสำรองไว้ในไฟล์ D:\BPP-VMS\Admin_Login_Info.txt เสมอ

🔄 ตอนที่ 2: การอัปเดตระบบเป็นเวอร์ชันล่าสุด

เมื่อโปรเจกต์มีการอัปเดตฟังก์ชันใหม่ และต้องการนำเวอร์ชันล่าสุดมาปรับใช้กับเครื่องเดิมที่มีอยู่แล้ว:

🔹 แบบที่ 1: เครื่องหลักที่มี Git (Online)

  1. เปิดโฟลเดอร์ D:\BPP-VMS
  2. ดับเบิลคลิกไฟล์ Update_System.bat
  3. ระบบจะดึงโค้ดล่าสุด (git pull) และสั่ง Docker ให้ทันที
  4. ข้อมูลไม่หาย 100%: บัญชีผู้ใช้, รหัสผ่าน, และคลิปวิดีโอเดิมคงอยู่ครบถ้วน

💡 หากต้องการส่งอัปเดตให้เครื่องลูก ให้ดับเบิลคลิก Export_Installer_Package.bat เพื่อสร้าง ZIP ส่งต่อ

🔹 แบบที่ 2: เครื่องหน้างานที่ลงผ่าน ZIP (Zero-GitHub)

  1. ดาวน์โหลด bpp-vms-installer.zip ล่าสุดจากเครื่องแม่ผ่าน https://vms.local/downloads/bpp-vms-installer.zip หรือก๊อปปี้ผ่าน USB Flash Drive
  2. แตกไฟล์ทับลงที่เดิม: แตกไฟล์ลงที่ไดรฟ์ D:\ ทับโฟลเดอร์ D:\BPP-VMS เดิมได้ทันที
  3. ปลอดภัย 100%: ZIP ไม่มีไฟล์ .env และไม่มีฐานข้อมูล จึงไม่ทับหรือลบข้อมูลเดิมแน่นอน
  4. ดับเบิลคลิกไฟล์ Update_System.bat เพื่อโหลดโค้ดใหม่เข้า Docker ทันที

📦 ตอนที่ 3: การย้ายข้อมูลจากเครื่องเดิม

หากต้องการย้ายกล้อง ผู้ใช้ และการตั้งค่าเดิมมาจากเครื่องเก่า:

  1. ที่เครื่องเดิม: ดับเบิลคลิก Export_System.bat แล้วนำไฟล์สำรองใส่ Flash Drive
  2. ที่เครื่องใหม่: นำไฟล์สำรองมาวางที่ไดรฟ์ D:\ แล้วดับเบิลคลิก Import_System.bat

❓ คำถามที่พบบ่อย (FAQ)

Q: เข้าเว็บ https://localhost แล้วขึ้นเตือนความปลอดภัย "Your connection is not private"?
A: เป็นปกติของใบรับรอง SSL ภายในเครื่อง ให้คลิกที่ Advanced (ขั้นสูง) > คลิก Proceed to localhost เพื่อเข้าสู่ระบบตามปกติ
Q: รหัสผ่านเข้าใช้งานครั้งแรกคืออะไร?
A: Username คือ admin และ Password คือ ChangeMeAdmin123! (หรือรหัสที่ตั้งไว้ในไฟล์ Admin_Login_Info.txt)
