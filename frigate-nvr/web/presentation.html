PART 1: MULTI-COMPANY ARCHITECTURE

1. สถาปัตยกรรมกระจายศูนย์ระดับกองร้อย (Multi-Company Federation Architecture)

กลไกการทำงานแบบกระจายศูนย์ระดับกองร้อย (Distributed Company Nodes + Inter-Sync)

ออกแบบระบบตามโครงสร้างกองร้อยตำรวจตระเวนชายแดน (ตชด.215, ตชด.214, ฯลฯ) เพื่อความคล่องตัวสูงสุด โดยมีหลักการทำงานสำคัญดังนี้:

1. เครื่องคอมหลักประจำกองร้อย

Company Host Node: แต่ละกองร้อยมีเครื่องคอมพิวเตอร์หลักเป็นของตัวเอง ทำหน้าที่เป็น NVR และ AI Engine รับสตรีมกล้องวงจรปิดในเขตพื้นที่รับผิดชอบของกองร้อยนั้นๆ

2. การเชื่อมต่อข้อมูลระหว่างกองร้อย

Inter-Company Sync: เครื่องคอมหลักของทุกกองร้อยสามารถเชื่อมต่อและซิงค์แลกเปลี่ยนข้อมูล Watchlist ป้ายทะเบียนรถต้องสงสัยคดียาเสพติดระหว่างกันได้แบบเรียลไทม์

3. ยืดหยุ่นในการเลือกใช้ NAS

Company or HQ NAS: แต่ละกองร้อยเลือกได้ว่าจะติดตั้ง NAS ประจำกองร้อยเอง หรือส่งไฟล์วิดีโอคลิปเหตุการณ์ไปสำรองไว้ที่ NAS รวมศูนย์ของ **กองกำกับการ**

PART 2: WORKFLOW

2. ขั้นตอนและกลไกการทำงาน (Operating Workflow)

ขั้นตอนการประมวลผลวิดีโอและ AI (Processing Pipeline)

1

RTSP Stream Ingestion

ดึงสตรีมหลัก (HD) สำหรับบันทึก และสตรีมย่อย (Sub-stream) จากกล้องวงจรปิดในพื้นที่กองร้อยเข้าสู่เครื่องคอมหลัก

2

AI Object Track & Zone Filtering

โมเดล YOLO วิเคราะห์ตรวจจับ Person, Car, Motorcycle, Truck ในโซนที่กำหนด หากพบวัตถุจะสร้าง Event ทันที

3

Thai LPR Sidecar Extraction

เมื่อพบยานพาหนะ LPR Service จะดึง Crop Frame ความละเอียดสูงมาสแกนตัวอักษรและหมวดจังหวัดภาษาไทย

PART 3: PROVISIONING

3. ขั้นตอนการเพิ่มและจัดการกล้อง (Camera Provisioning Guide)

ขั้นตอนการเพิ่มกล้องใหม่เข้าสู่ระบบ

  1. เข้าสู่ระบบด้วยสิทธิ์ Admin: ล็อกอินผ่านหน้าเว็บ `https://localhost/login.html`
  2. เปิดหน้าตั้งค่าระบบ (Settings): คลิกปุ่มฟันเฟืองมุมขวาบน เลือกแถบ "จัดการกล้อง"
  3. กรอก RTSP Stream URL: ใส่ Stream URL หลัก (Main) และสตรีมย่อย (Sub-stream)
  4. กดปุ่ม "ทดสอบ": ระบบจะดึง Snapshot ทดสอบความสมบูรณ์ของภาพนิ่งเรียลไทม์
  5. เลือกวัตถุที่ต้องการให้ AI ตรวจจับ: ติ๊กเลือก Person, Car, Motorcycle, Truck หรือตีกรอบ Detection Zone
  6. กด "บันทึก": ระบบจะเขียน Config อะตอมมิกและรีสตาร์ทบริการแบบไม่กระทบประวัติคลังเหตุการณ์ย้อนหลัง

ทดลองจำลองฟอร์มเพิ่มกล้อง (Interactive Camera Demo)

PART 5: SECURITY

5. ระบบความปลอดภัยและความน่าเชื่อถือ (Security & RBAC Architecture)

ตารางสถาปัตยกรรมความปลอดภัยและการป้องกันข้อมูล (Security Control Matrix)

มิติความปลอดภัย กลไกที่ใช้บังคับ (Implementation Mechanism) ผลลัพธ์การป้องกัน (Security Benefit) สถานะการทดสอบ
Authentication JWT Token บรรจุใน HttpOnly, SameSite=Strict Cookie ป้องกันการถูกขโมย Session ผ่าน XSS / Script Injection 100% ✓ PASSED
Password Storage Bcrypt Password Hashing (Salt Work Factor = 12) ป้องกันการถอดรหัสรหัสผ่านแม้ฐานข้อมูลถูกเปิดเผย ✓ PASSED
Authorization (RBAC) Admin-Only FastAPI Dependency Gate (`require_admin`) จำกัดสิทธิ์แก้ไข Config/เพิ่มกล้อง เฉพาะบัญชี Admin เท่านั้น ✓ PASSED
Inter-service Security Constant-time Shared Secret Header Verification ไม่อนุญาตให้คอนเทนเนอร์ภายนอกเรียกใช้งาน API โดยตรง ✓ PASSED
FileSystem ACL NTFS/Linux Restrict Access (Administrators & SYSTEM only) ป้องกันผู้ใช้ทั่วไปในเครื่องโฮสต์เข้าถึงไฟล์รหัสผ่าน/โทะเคน ✓ PASSED
PART 6: ROADMAP

6. แผนการพัฒนาระบบในอนาคต (Future Development Roadmap)

PHASE 1 (ระยะสั้น 1 - 6 เดือน)

อัปเกรด AI LPR 2.0 & Dedicated Night-Vision

  • Multi-Country LPR Engine: พัฒนาโมเดล AI อ่านป้ายทะเบียน สปป.ลาว และกัมพูชา เพื่อรองรับด่านชายแดน
  • Global Shutter Night-Vision Cameras: ติดตั้งกล้อง LPR ชนิดอินฟราเรดสปีดสูง จับภาพกลางคืน 100%
  • Auto Cold Storage Backup: ระบบสำรองไฟล์วิดีโอเหตุการณ์ย้อนหลังไป NAS อัตโนมัติเมื่อดิสก์เต็ม
PHASE 2 (ระยะกลาง 6 - 12 เดือน)

Drone AI Recon & Mobile Operations App

  • Drone AI Reconnaissance Integration: เชื่อมสตรีมโดรนลาดตระเวนเข้า VMS ตรวจจับคน/รถตามช่องทางธรรมชาติ
  • Mobile Operations App (iOS/Android): แอปพลิเคชันสมาร์ทโฟนสำหรับชุดสืบสวน รับ Real-time Alert พร้อมพิกัด GPS
  • Live Stream Share Link: ระบบแชร์สตรีมกล้องสดแบบจำกัดเวลา (Expiring Link) ให้หน่วยงานร่วมปฏิบัติงาน
PHASE 3 (ระยะยาว 1 - 2 ปี)

Behavioral Analytics & Predictive Intelligence

  • Behavioral AI Analysis: วิเคราะห์พฤติกรรมเสี่ยง (เช่น รถขับวนซ้ำผิดปกติ, รถจอดในจุดเปลี่ยวเป็นเวลานาน)
  • Central Big Data Federation: เชื่อมต่อ API ตรงกับศูนย์ปฏิบัติการ ศปส.ตร. และ ป.ป.ส. ส่วนกลาง
  • License Plate Anomaly Detection: ตรวจจับความผิดปกติของแผ่นป้ายทะเบียนสวม/ป้ายทะเบียนปลอม
PHASE 4 (ความมั่นคงขั้นสูง)

Person Re-Identification & Cross-Cam Tracking

  • Person Re-ID & Face Recognition: ระบบค้นหาและติดตามเส้นทางเป้าหมายข้ามทุกกล้องในเครือข่าย
  • Route Heatmap & Timeline Reconstruction: สร้างแผนผังเส้นทางเดินทางย้อนหลังของรถเป้าหมายอัตโนมัติ
  • Automated Forensic Report: ระบบสร้างรายงานสรุปพยานหลักฐานสำหรับส่งดำเนินคดีอาญา
PART 7: STANDARD SPECIFICATIONS & REMOTE ACCESS

7. สเปกมาตรฐานเครื่องคอมพิวเตอร์กองร้อย, NAS และคำแนะนำการดูวิดีโอเรียลไทม์จากภายนอกผ่าน DDNS

1. สเปกมาตรฐานเครื่องคอมพิวเตอร์หลักประจำกองร้อย (Standard Company Host PC)

  • CPU มาตรฐาน: Intel Core i5-12500 หรือเทียบเท่าขึ้นไป (เช่น i5-13500 / i5-14500 / AMD Ryzen 5 7600X ขึ้นไป) เพื่อรองรับการถอดรหัสวิดีโอหลายสตรีม
  • หน่วยความจำ (RAM): 32 GB - 64 GB ขึ้นไป (DDR4/DDR5) เพื่อความลื่นไหลในการรัน Docker 7 Microservices + Caching + WebRTC Stream
  • การ์ดจอเร่งความเร็ว AI (GPU): NVIDIA GeForce RTX 4060 Ti / RTX 5060 Ti ขึ้นไป (12GB-16GB VRAM) สำหรับการประมวลผล YOLO และอ่านป้ายทะเบียน LPR แบบขนาน
  • ดิสก์ภายในเครื่อง (SSD): NVMe M.2 SSD อย่างน้อย 1 TB ขึ้นไป สำหรับติดตั้ง OS, Docker Engine, SQLite/PostgreSQL DB และ Cache เหตุการณ์

2. ข้อแนะนำสถานที่ตั้ง NAS และคำนวณขนาดความจุ (NAS Location & Capacity Guide)

  • สถานที่ตั้ง NAS (คำแนะนำ):
    • ตั้งไว้ที่ กองกำกับการ (กิโล/กก.) - ทางเลือกหลักที่แนะนำ: รวมศูนย์งบประมาณ NAS ขนาดใหญ่ไว้ที่เดียว ดูแลรักษาง่ายโดยทีม IT กองกำกับการ และป้องกันข้อมูลสูญหายจากกองร้อยชายแดน
    • ตั้งไว้ประจำแต่ละกองร้อย: ใช้ NAS ขนาดเล็ก (4-8 Bay) ประจำกองร้อย หากเป็นพื้นที่ชายแดนห่างไกลที่อินเทอร์เน็ตไม่เสถียร
  • ขนาดความจุ NAS ที่แนะนำ:
    • คำนวณบันทึกคลิปวิดีโอ 16 กล้อง HD ย้อนหลัง 90 วัน -> ใช้พื้นที่ประมาณ **40 - 45 TB**
    • ความจุจัดซื้อที่แนะนำ (รวม RAID Protection): ควรใช้ NAS ความจุสุทธิ 60 TB - 100 TB (เช่น Enterprise Hard Drive 16TB - 20TB จำนวน 6-8 ลูก)

3. ชุดกล้องซ่อนพรางสำหรับการซุ่มยิง

  • Covert Pinhole Cameras: กล้องรูเข็มขนาดจิ๋วซ่อนในตู้ไฟ/เสาไฟ สำหรับงานซุ่มยิงทางการข่าว
  • Body-Worn Cameras (BWC): กล้องติดตัวเจ้าหน้าที่ชุดเคลื่อนที่เร็ว ลิงก์สตรีม 5G กลับคอมพิวเตอร์กองร้อย
  • Low-light Sensor: จับภาพสีชัดเจนในสภาวะแสงน้อยกลางคืน

4. เครือข่ายเชื่อมต่อเราเตอร์ 5G VPN

  • Industrial Router: Teltonika RUTX50 / Peplink MAX 5G Router ทนทานระดับการทหาร
  • Dual SIM Auto-Failover: ใส่ SIM 5G 2 ค่าย สลับสายอัตโนมัติเมื่อสัญญาณดับ
  • WireGuard VPN Tunnel: เข้ารหัสความปลอดภัย 256-bit เชื่อมกองร้อยกับกองกำกับการ

5. คู่มือเปิดดูวิดีโอเรียลไทม์จากภายนอกผ่าน DDNS & WebRTC

  • 1. Forward Port ที่เราเตอร์กองร้อย:
    • Port 443 (HTTPS): สำหรับ Web Dashboard & Login Auth
    • Port 8555 (TCP/UDP): สำหรับ WebRTC Real-Time Stream (<0.2s)
  • 2. เข้าชมผ่าน DDNS Domain:
    พิมพ์ `https://<ชื่อ-DDNS-กองร้อย>.ddns.net` บนสมาร์ทโฟน/แท็บเล็ต ดูสดได้จากทุกที่ทั่วโลก
  • 3. ทางเลือกเสริมความปลอดภัยสูงสุด (VPN App):
    รัน WireGuard VPN บนมือถือเพื่อดูผ่าน IP ภายใน ป้องกันแฮกเกอร์ 100%
