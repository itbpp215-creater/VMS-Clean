# File Access Rules

> **⚠️ กฎการเข้าถึงและจัดการไฟล์ (File Access Rules)**
> กฎเหล่านี้มีไว้สำหรับ AI Agent และ Developer เพื่อป้องกันไม่ให้ความลับหลุดรอด หรือทำให้ระบบไฟล์พัง

### 🚫 1. ไฟล์ที่ห้ามแตะต้อง ห้าม Track และห้าม Commit เด็ดขาด (Secret Rules)
*   **`.env`**: ไฟล์นี้เก็บความลับทุกอย่าง ห้ามนำมาเปิดเผยในแชท ห้าม Commit ลง Git เด็ดขาด
*   **โฟลเดอร์ `LicensePlateRECOG/model/`**: ห้าม Track โมเดล AI (`.pt`) เพราะอาจมี credential ฝังอยู่ข้างใน
*   **โฟลเดอร์ข้อมูลรันไทม์**: ห้ามยุ่งกับฐานข้อมูล (Database) และไฟล์วิดีโอที่บันทึกไว้ (Recordings)
*   **ไฟล์ `admin-credential.once`**: ไฟล์รหัสผ่านชั่วคราว ถ้าสร้างขึ้นมาใช้แล้ว ต้องลบทิ้งเสมอ

### ⚙️ 2. กฎการเข้าถึงไฟล์ Configuration (`config/config.yml`)
*   **Git-managed เท่านั้น**: ไฟล์นี้ต้องแก้ผ่านโค้ดและ Git ห้ามแก้บนเซิร์ฟเวอร์โดยตรง
*   **ห้ามมีรหัสผ่าน (No Inline Credentials)**: ในไฟล์ `config.yml` ห้ามใส่รหัสผ่านกล้อง หรือ Token ตรงๆ ต้องใช้ตัวแปร `{FRIGATE_...}` เท่านั้น (แล้วไปดึงค่าจาก `.env` อีกที)

### 🔒 3. กฎการจัดการโฟลเดอร์และสิทธิ์ (Permissions)
*   โฟลเดอร์ `auth`, `certs`, `lpr`, `dashboard-settings`, `backups`, และ `lpr-data` เป็นข้อมูลสำคัญที่มีการจัดการสิทธิ์ด้วยสคริปต์ `scripts/harden-windows-acl.ps1`
*   **Agent ห้ามพยายามเปลี่ยนสิทธิ์ (Permission/ACL)** ของโฟลเดอร์เหล่านี้เองโดยพลการ และห้ามเผลอลบโฟลเดอร์เหล่านี้ทิ้ง

### 📝 4. กฎการเข้าถึงไฟล์เอกสาร (Documentation)
*   **การแก้ไขไฟล์ `.md`**: ไฟล์เอกสารทุกตัวและสิ่งที่อยู่ใน `docs/` จะถูกละเว้น (Ignore) จาก CI/CD Pipeline ดังนั้นเวลาแก้ไขเอกสาร ระบบ Production จะไม่รีสตาร์ท
*   **No Secrets in Markdown**: ห้ามเผลอใส่ รหัสผ่าน, IP จริงของกล้อง หรือ Token ลงใน Session logs หรือไฟล์ Markdown อื่นๆ เด็ดขาด
