# 🌐 แผนสถาปัตยกรรมเชื่อมต่อและเข้าใช้งานจากภายนอก (Remote Access & Mesh Architecture Plan)

> **เอกสารอ้างอิงหลัก:** ใช้สำหรับกางสรุปแนวทางทันทีเมื่อมีการสอบถามเกี่ยวกับการเข้าใช้งานจากภายนอก (Remote Access) การตั้งค่า DDNS และการทำ WireGuard Mesh ข้ามหน่วยงาน

---

## 📌 1. ภาพรวมสถาปัตยกรรมแบบผสมผสาน (Hybrid Architecture Overview)

ระบบถูกออกแบบแยกเป็น **2 ช่องทางหลัก** เพื่อรองรับทั้งความสะดวกของเจ้าหน้าที่ภาคสนามและความปลอดภัยข้ามหน่วยงาน:

```
                                  [ อินเทอร์เน็ตสาธารณะ ]
                                             │
                 ┌───────────────────────────┴───────────────────────────┐
                 ▼ (ช่องทางที่ 1: หน้าบ้าน - DDNS)                        ▼ (ช่องทางที่ 2: หลังบ้าน - WireGuard Mesh)
    [ มือถือเจ้าหน้าที่ภาคสนาม ]                                [ กองร้อยอื่น & กล้องหน่วยงานอื่น ]
  • ไม่ต้องลงแอปแม้แต่แอปเดียว                                    • MikroTik Site-to-Site WireGuard Mesh
  • เปิดเบราว์เซอร์เข้า HTTPS DDNS ได้ทันที                        • สตรีมภาพกล้องวงจรปิดข้ามหน่วยงาน
  • ดูวิดีโอสด, ล็อกอิน, บันทึกรายงาน, แชท                            • Sync ข้อมูลป้ายทะเบียนระหว่างค่าย
                 │                                                       │
                 └───────────────────────────┬───────────────────────────┘
                                             ▼
                                ┌───────────────────────────┐
                                │   BPP-VMS Center Server   │
                                │   (Dashboard + Frigate)   │
                                └───────────────────────────┘
```

## 📱 2. ช่องทางที่ 1: หน้าบ้านสำหรับมือถือเจ้าหน้าที่ (No-App Experience)

* **เป้าหมาย:** เจ้าหน้าที่ภาคสนามเปิดเบราว์เซอร์ (Safari บน iOS / Chrome บน Android) แล้วพิมพ์ URL เช่น `https://bpp215.ddns.net` ใช้งานได้ทันที **โดยไม่ต้องติดตั้งแอปพลิเคชันใดๆ เพิ่มเติม**
* **การเปิดพอร์ตบน Router (Forward Ports) รวม 2 พอร์ต:**
  1. **พอร์ต 443 (TCP):** หน้าเว็บ Dashboard, ล็อกอิน, จัดการกล้อง, LPR, ระบบรายงาน และ Chat Widget
  2. **พอร์ต 8555 (TCP และ UDP):** สตรีมวิดีโอสด WebRTC (Sub-second Latency) **ต้องเปิดทั้ง TCP และ UDP เพื่อให้ภาพกล้องสดบนมือถือไม่จอดำ**

## 🕸️ 3. ช่องทางที่ 2: หลังบ้าน WireGuard Mesh (ระหว่างกองร้อย & กล้องภายนอก)

* **เป้าหมาย:** เชื่อมต่อ Router MikroTik ของทุกกองร้อยเข้าด้วยกันเป็นเครือข่ายใยแมงมุม (Full Mesh VPN Network)
* **การใช้งาน:**
  1. **ดึงกล้องภายนอก:** ดึงสตรีม RTSP จากกล้องของกองร้อยอื่นผ่าน IP วง Mesh (เช่น `rtsp://admin:pass@192.168.20.50:554/...`)
  2. **ซิงค์ป้ายทะเบียนเฝ้าระวัง (Watchlist Federation):** ซิงค์ข้อมูลรถต้องสงสัยระหว่างเซิร์ฟเวอร์ทุกกองร้อยอัตโนมัติ 24 ชม.
* **การตั้งค่า `.env` บน BPP-VMS:**
  ```env
  BPP_FEDERATION_ALLOW_CIDR=127.0.0.1/32,192.168.10.0/24,192.168.20.0/24,192.168.30.0/24
  WATCHLIST_ALLOWED_ORIGINS=https://bpp215.ddns.net
  ```

## 🛠️ 4. ทางแก้ปัญหากรณีบางกองร้อยไม่มี DDNS หรือติด CGNAT (เน็ตซิม 4G/5G)

หากกองร้อยใดไม่มี DDNS หรือไม่สามารถ Forward Port ได้ ให้เลือกใช้ทางแก้ปัญหาดังนี้:

| ทางเลือก | วิธีการดำเนินการ | สิ่งที่ได้ |
| :--- | :--- | :--- |
| **1. MikroTik IP Cloud** | เปิดเมนู `IP` ➔ `Cloud` ➔ `DDNS Enabled` บน MikroTik | ได้ชื่อโดเมนฟรี เช่น `123456789abc.sn.mynetname.net` โดยไม่ต้องซื้อ DDNS |
| **2. วิ่งผ่าน Mesh เข้ากองร้อยหลัก** | ให้มือถือเข้าผ่าน DDNS กองร้อยหลัก แล้วย้ายทราฟฟิกผ่านท่อ WireGuard Mesh ไปกองร้อยนั้น | เข้าใช้งานได้โดยไม่ต้องมี DDNS ของตัวเอง |
| **3. Cloudflare Tunnel** | รัน `cloudflared` บนเซิร์ฟเวอร์ BPP-VMS ของกองร้อยนั้น | ได้โดเมน HTTPS (เช่น `https://camp3.bpp215.org`) เข้าได้ทันทีโดยไม่ต้องเปิดพอร์ต Router และไม่ต้องมี Public IP |
| **4. Telegram / LINE Bot** | สั่งงาน บันทึกรายงาน และรับแจ้งเตือนผ่าน Bot | ทำงานผ่าน Outbound Webhook ใช้งานได้ 100% บนทุกเน็ตซิม |

## 📌 5. สรุปแนวทางปฏิบัติ (Action Checklist)

1. **สำหรับมือถือเจ้าหน้าที่:** แจ้งชื่อโดเมน DDNS หรือ Cloudflare URL + พอร์ต 443/8555 ให้เปิดผ่านเบราว์เซอร์ได้ทันที
2. **สำหรับระบบหลังบ้าน:** เชื่อมต่อ MikroTik WireGuard Mesh ระหว่างค่าย แล้วใส่ IP Subnet ลงใน `BPP_FEDERATION_ALLOW_CIDR` ของ `.env`
