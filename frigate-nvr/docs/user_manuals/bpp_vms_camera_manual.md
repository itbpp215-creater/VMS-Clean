# คู่มือการจัดการกล้อง (Camera Management Guide) ระบบ BPP-VMS

คู่มือฉบับนี้อธิบายขั้นตอนการเพิ่ม แก้ไข และลบกล้องในระบบ BPP-VMS ซึ่งรองรับทั้ง **กล้องภายในหน่วยงานของท่านเอง** และ **กล้องที่ดึงมาจากหน่วยงานอื่น (Federation)** ในเครือข่าย

---

## 1. การเพิ่มกล้องภายในหน่วยงาน (Local Camera)
ใช้สำหรับเพิ่มกล้องวงจรปิดที่ติดตั้งในพื้นที่ของท่านเอง (เช่น กล้อง IP Camera, NVR, DVR)

**ขั้นตอนการทำงาน:**
1. ไปที่แท็บ **"กล้องในระบบ (NVR)"** บนหน้าต่างตั้งค่า
2. กดปุ่ม **"เพิ่มกล้องใหม่"** ที่มุมขวาบน
3. **ข้ามช่องดึงข้อมูล:** ข้ามกล่องตัวเลือกที่เขียนว่า `[- หน่วยงานอื่น -]` ไม่ต้องกดเลือกอะไร
4. **กรอกข้อมูลกล้อง:**
   * **ชื่อกล้อง:** ตั้งชื่อภาษาอังกฤษ ตัวเลข หรือขีดล่าง (ห้ามเว้นวรรค) เช่น `cam_gate_01`
   * **กลุ่มของกล้อง:** ระบุจุดติดตั้ง (เช่น `อาคารกองบังคับการ`) เพื่อให้จัดกลุ่มใน Dashboard ได้สวยงาม
   * **RTSP URL (Main Stream):** นำลิงก์สตรีมของกล้องมากรอกใส่ (ช่องนี้บังคับ)
   * **RTSP URL (Sub Stream):** ลิงก์สตรีมความละเอียดต่ำ (ถ้ามี)
5. **การตั้งค่าการใช้งาน:**
   * แนะนำให้ **"ติ๊กถูก"** ทั้ง `เปิดระบบ AI (Detect)` และ `บันทึกวิดีโอ (Record)` เพื่อให้ระบบวิเคราะห์ป้ายทะเบียนและบันทึกภาพตลอด 24 ชั่วโมง
6. กดปุ่ม **"ตกลง"** ระบบจะทำการบันทึกและเชื่อมต่อกล้องทันที

---

## 2. การดึงภาพกล้องจากหน่วยงานอื่น (Federated Camera)
ใช้สำหรับขอดูกล้องที่ติดตั้งอยู่กับ Server ของหน่วยงานอื่นในเครือข่าย (เช่น กองร้อย A ขอดูภาพจาก กองร้อย B) โดยมี 2 วิธีให้เลือกใช้งาน

### วิธีที่ 2.1: การดึงแบบรวดเดียว (ซิงค์ทั้งหมด) - *แนะนำ*
หากหน่วยงานปลายทางมีกล้องหลายตัว และคุณต้องการนำเข้ากล้องทั้งหมดในคลิกเดียว:
1. ไปที่แท็บ **"กล้องในระบบ (NVR)"** และกดปุ่ม **"เพิ่มกล้องใหม่"**
2. ที่มุมขวาของหัวข้อ "เพิ่มกล้องใหม่" ให้คลิกที่ Dropdown **`[- หน่วยงานอื่น -]`**
3. เลือกชื่อหน่วยงานปลายทาง
4. ระบบจะแสดงปุ่ม **"ซิงค์ทั้งหมด"** ขึ้นมาข้างๆ ให้กดที่ปุ่มนี้
5. ระบบจะขึ้นหน้าต่างยืนยัน แจ้งจำนวนกล้องทั้งหมดที่จะดึงเข้ามา กดยืนยันเพื่อดำเนินการ
6. **การทำงานของระบบ:** 
   * ระบบจะดึงกล้องทั้งหมดเข้ามา และจัดเข้า **กลุ่ม (Group)** ตามชื่อของหน่วยงานนั้นๆ โดยอัตโนมัติ
   * เพื่อป้องกันไม่ให้เซิร์ฟเวอร์ของคุณทำงานหนักเกินไป ระบบจะ **ปิด AI (Detect)** และ **ปิดบันทึกวิดีโอ (Record)** ของกล้องที่นำเข้ามาใหม่ให้เป็นค่าเริ่มต้น
   * ระบบจะข้ามกล้องที่เคยนำเข้ามาแล้วให้อัตโนมัติ (ป้องกันการซ้ำซ้อน)
   * เมื่อเสร็จสิ้น ระบบจะรีสตาร์ทตัวเอง 1 ครั้งเพื่อใช้งานกล้องใหม่

### วิธีที่ 2.2: การดึงทีละกล้อง (Import Single Camera)
หากคุณต้องการเลือกดึงเฉพาะบางกล้อง:
1. ไปที่แท็บ **"กล้องในระบบ (NVR)"** และกดปุ่ม **"เพิ่มกล้องใหม่"**
2. เลือกชื่อหน่วยงานจาก Dropdown **`[- หน่วยงานอื่น -]`**
3. รอสักครู่ ระบบจะไปดึงรายชื่อกล้องจากหน่วยงานนั้นมาแสดงใน Dropdown อันที่สอง **`[- เลือกกล้อง -]`**
4. เลือกกล้องที่ต้องการ แล้วปุ่ม **"ดึงข้อมูล"** จะแสดงขึ้นมา ให้กดปุ่มนั้น
5. ระบบจะกรอก RTSP URL ให้อัตโนมัติ คุณสามารถเปลี่ยน "ชื่อกล้อง" หรือ "กลุ่มของกล้อง" ได้ตามต้องการ
6. **ข้อควรระวัง:** แนะนำให้ปล่อยค่าปิด AI และบันทึกวิดีโอไว้ เพื่อประหยัดแบนด์วิดท์ข้ามเครือข่าย
7. กดปุ่ม **"ตกลง"** เพื่อบันทึก


---

## 3. การแก้ไขและการลบกล้อง

**การแก้ไขข้อมูลกล้อง (Edit):**
1. ในหน้ารายชื่อกล้อง (แท็บ "กล้องในระบบ") ให้คลิกที่ปุ่มไอคอน **"ฟันเฟือง"** หลังชื่อกล้องที่ต้องการ
2. หน้าต่างจะแสดงข้อมูลเดิมขึ้นมา คุณสามารถแก้ไข ชื่อกลุ่ม, ลิงก์ RTSP หรือสลับการเปิด/ปิด AI และบันทึกภาพได้
3. กดปุ่ม **"ตกลง"** เพื่อบันทึกการเปลี่ยนแปลง

**การลบกล้อง (Delete):**
1. ในหน้ารายชื่อกล้อง ให้คลิกที่ปุ่มไอคอน **"ถังขยะสีแดง"** หลังชื่อกล้องที่ต้องการลบ
2. ระบบจะขึ้นหน้าต่างยืนยันการลบ
3. เมื่อกดยืนยัน กล้องจะถูกถอดออกจากระบบทันที (รวมถึงในหน้า Dashboard ด้วย)

---

## 💡 คำแนะนำเพิ่มเติมสำหรับแอดมิน
* หากรายชื่อใน Dropdown `[- หน่วยงานอื่น -]` ว่างเปล่า หรือไม่มีหน่วยงานที่คุณต้องการ ให้แอดมินระบบเข้าไปเพิ่ม IP ของหน่วยงานนั้นๆ ในเมนู **Settings -> Nodes** เสียก่อน
* การบันทึกรหัสผ่านกล้อง: หากไม่ต้องการพิมพ์รหัสผ่านกล้องลงไปโต้งๆ ในช่อง RTSP URL คุณสามารถใช้ตัวแปรลับ (Placeholder) เช่น `{FRIGATE_CAMERA_USER}:{FRIGATE_CAMERA_PASS}` แล้วไปตั้งค่ารหัสผ่านจริงไว้ในไฟล์ `.env` ของเซิร์ฟเวอร์แทนได้
