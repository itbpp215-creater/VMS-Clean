# 📸 คู่มือการใช้งาน: ระบบจัดการกล้อง BPP-VMS
ยินดีต้อนรับครับ! คู่มือนี้จะสอนวิธี **"เพิ่มกล้องวงจรปิด"** เข้ามาในระบบแบบง่ายๆ ทีละขั้นตอน เหมาะสำหรับผู้เริ่มต้นครับ

ในระบบของเรา คุณสามารถเพิ่มกล้องได้ 2 แบบคือ:
1. **กล้องของหน่วยงานเราเอง** (กล้องที่ติดตั้งอยู่ในค่าย/พื้นที่ของเรา)
2. **กล้องของหน่วยงานอื่น** (ขอดูกล้องของหน่วยอื่นในเครือข่าย)

👉 กดปุ่มลูกศร **ถัดไป (Next)** ด้านล่างเพื่อเริ่มเรียนรู้ได้เลยครับ

# ⚙️ ขั้นตอนที่ 1: เข้าสู่หน้าต่างตั้งค่า

ก่อนอื่น เราต้องเปิดหน้าต่างสำหรับตั้งค่ากล้องขึ้นมาก่อนครับ

1. สังเกตที่เมนูด้านซ้ายล่างของหน้าจอหลัก
2. คลิกที่ปุ่ม **"ฟันเฟือง" (ตั้งค่า)**
3. หน้าต่างการตั้งค่าจะเด้งขึ้นมาตรงกลางจอ
4. สังเกตด้านบนของหน้าต่าง จะมีแท็บคำว่า **"กล้องในระบบ (NVR)"** ให้คลิกที่แท็บนี้ครับ
5. จากนั้นคลิกปุ่ม **"เพิ่มกล้องใหม่"** ที่มุมขวาบน

<!-- slide -->
# 🏢 แบบที่ 1: การเพิ่มกล้องของหน่วยงานเราเอง

ถ้าคุณต้องการเพิ่มกล้องที่อยู่ในพื้นที่ของคุณเอง ให้ทำตามนี้ครับ:

1. **ข้ามช่องดึงข้อมูล:** ไม่ต้องสนใจกล่องที่เขียนว่า "[- หน่วยงานอื่น -]" ปล่อยผ่านไปได้เลยครับ
2. **ชื่อกล้อง:** ตั้งชื่อกล้องเป็นภาษาอังกฤษ ตัวเลข หรือขีดล่าง เช่น `gate_01` (ห้ามเว้นวรรคและห้ามใช้ภาษาไทยนะครับ)
3. **กลุ่มของกล้อง:** พิมพ์ชื่อจุดที่ติดตั้งเป็นภาษาไทยได้เลย เช่น `ประตูทางเข้าหลัก` หรือ `โรงอาหาร`
4. **RTSP URL:** นำลิงก์สัญญาณภาพจากกล้องของคุณ (หรือช่างกล้อง) มาวางใส่ในช่องนี้ครับ ลิงก์มักจะขึ้นต้นด้วย `rtsp://`

👉 กรอกข้อมูลเสร็จแล้ว ไปดูสไลด์ถัดไปเพื่อตั้งค่า AI กันครับ

<!-- slide -->
# 🌐 แบบที่ 2: การดึงภาพกล้องจากหน่วยงานอื่น

หากคุณต้องการดูกล้องของหน่วยงานอื่น (เช่น กองร้อยเพื่อนบ้าน) เรามี 2 วิธีง่ายๆ ให้เลือกครับ:

**วิธี A: ดึงรวดเดียวทั้งหมด (แนะนำ!)**
1. ด้านขวาของคำว่า "เพิ่มกล้องใหม่" จะมีกล่อง **"[- หน่วยงานอื่น -]"** ให้เลือกชื่อหน่วยงาน
2. ปุ่ม **"ซิงค์ทั้งหมด"** จะโผล่ขึ้นมา! กดปุ่มนี้ได้เลย
3. กดยืนยัน ระบบจะดึงกล้องทุกตัวของหน่วยงานนั้นเข้ามา จัดกลุ่มให้อัตโนมัติ ปิด AI ให้เรียบร้อย และรีสตาร์ทตัวเอง จบในคลิกเดียว!

**วิธี B: ดึงมาทีละกล้อง**
1. เลือกชื่อหน่วยงาน จากนั้นจะมีกล่อง **"[- เลือกกล้อง -]"** โผล่มา
2. เลือกชื่อกล้องที่ต้องการ แล้วกดปุ่ม **"ดึงข้อมูล"**
3. ระบบจะกรอกลิงก์ให้ทั้งหมด คุณสามารถแก้ชื่อกล้องได้ตามใจชอบ
4. กด "ตกลง" ด้านล่าง

👉 ไปดูคำแนะนำเรื่องการบันทึกภาพในสไลด์ถัดไปครับ

<!-- slide -->
# 🤖 ขั้นตอนสุดท้าย: การตั้งค่า AI และบันทึกภาพ

ด้านล่างสุดของฟอร์ม จะมีกล่องให้ติ๊กถูกสองกล่อง คือ **เปิดระบบ AI** และ **บันทึกวิดีโอ**

> [!TIP]
> **สำหรับกล้องของหน่วยงานเราเอง:**
> แนะนำให้ **ติ๊กถูกทั้งสองช่อง** ครับ เพื่อให้ระบบบันทึกภาพ 24 ชั่วโมง และช่วยตรวจจับคน รถ หรือป้ายทะเบียนให้เราอัตโนมัติ

> [!WARNING]
> **สำหรับกล้องที่ดึงมาจากหน่วยงานอื่น:**
> ระบบจะฉลาดพอที่จะ **เอาติ๊กถูกออกให้** เพื่อประหยัดอินเทอร์เน็ต! แนะนำว่า **ไม่ต้องไปติ๊กเปิดมันนะครับ** ภาพจะยังโผล่มาให้ดูสดๆ ในหน้าหลักปกติ แต่จะไม่แอบสูบเน็ตตลอดเวลาครับ

เมื่อตั้งค่าเสร็จแล้ว กดปุ่ม **"ตกลง"** สีม่วงด้านล่างสุดได้เลยครับ
