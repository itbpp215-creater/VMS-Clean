# BPP 215 / PRERIMWATCH — Pointed Shield V6

## Structure

- Pointed six-edge shield replaces the circular outer silhouette.
- Approved smart-visor sloth is cropped from the unchanged source; the face, visor, headset, circuits, shoulders, and aperture are not regenerated.
- One oversized angular frame extends beyond both shield sides.
- `BPP 215` appears first and is the largest title.
- `PRERIMWATCH` follows underneath using the same condensed italic gradient, keyline, inner edge, and shadow.
- Thai unit wording uses the same visual treatment on the upper shield arc.
