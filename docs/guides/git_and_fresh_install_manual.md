## 1. ภาพรวม: ระบบติดตั้งอัตโนมัติ 1-Click

ในเวอร์ชันก่อนหน้า การนำระบบไปติดตั้งบนเครื่องใหม่ต้องอาศัยการก๊อปปี้ไฟล์ `.env.example` มาแก้เป็น `.env` และต้องพิมพ์คำสั่งยาวๆ ใน PowerShell ซึ่งมักติดขัด Error เช่น:
- `AUTH_AUDIT_SHARED_SECRET is required` (เพราะไม่ได้สุ่มสร้างรหัสความปลอดภัย 64 หลัก)
- `FRIGATE_PRASAT_USER is required` (เพราะไม่มีค่าเริ่มต้นสำหรับกล้อง)
- ต้องรันคำสั่ง CLI ที่ซับซ้อนเพื่อสร้าง User `admin`

**ระบบใหม่ (เวอร์ชันปัจจุบัน):**
ทีมงานได้พัฒนาตัวช่วยติดตั้งอัตโนมัติ **`Setup_New_Machine.bat`** และตัวช่วยอัปเดต **`Update_System.bat`** ไว้ที่โฟลเดอร์หลัก (`D:\BPP-VMS`) เรียบร้อยแล้ว:
- ⚡ **สุ่มสร้างรหัสความปลอดภัย (Cryptographic Secrets) ให้อัตโนมัติ 100%**
- ⚡ **สร้างใบรับรองความปลอดภัย HTTPS (SSL Certificate) ให้อัตโนมัติ**
- ⚡ **เปิดบริการ Docker ครบทั้ง 17 คอนเทนเนอร์โดยไม่มี Error**
- ⚡ **ตั้งค่าบัญชี Admin เริ่มต้น พร้อมเปิดหน้าเว็บให้ทันที**

## ตอนที่ 1: ขั้นตอนการติดตั้งบนเครื่องใหม่

### 📋 สิ่งที่ต้องเตรียมก่อนเริ่ม:
1. เครื่องคอมพิวเตอร์ระบบปฏิบัติการ **Windows 10 หรือ Windows 11 (64-bit)**
2. พื้นที่ว่างในไดรฟ์ `D:` อย่างน้อย 20 GB ขึ้นไป
3. ติดตั้งโปรแกรม **Docker Desktop** ไว้ที่เครื่อง ([ดาวน์โหลดที่นี่](https://www.docker.com/products/docker-desktop/))

---

### 🚀 3 สเต็ปการติดตั้งแบบ 1-Click:

#### 🔹 สเต็ปที่ 1: เปิดโปรแกรม Docker Desktop
1. ดับเบิลคลิกเปิดโปรแกรม **Docker Desktop** บนหน้า Desktop ของท่าน
2. รอประมาณ 30 วินาที จนกระทั่งไอคอนปลาวาฬที่มุมซ้ายล่างของโปรแกรมเปลี่ยนเป็น **สีเขียว (Engine running)**

#### 🔹 สเต็ปที่ 2: นำโฟลเดอร์โปรเจกต์มาวางไว้ที่ `D:\BPP-VMS` (Zero-GitHub — ปลอดภัย 100%)
> 🛡️ **ความปลอดภัยสูงสุด:** ท่าน**ไม่ต้องล็อกอินบัญชี GitHub** และ**ไม่ต้องกรอก Personal Access Token (PAT)** บนเครื่องใหม่ให้เสี่ยงต่อการถูกแฮกหรือรั่วไหล เลือกช่องทางที่สะดวกได้เลย:

- **วิธีที่ 1 (สะดวกที่สุด — ดาวน์โหลดผ่านหน้าเว็บ):**
  1. เปิดเบราว์เซอร์จากเครื่องใหม่ แล้วดาวน์โหลดไฟล์ชุดติดตั้งผ่านลิงก์โดยตรง:
     `https://vms.local/downloads/bpp-vms-installer.zip` (หรือกดดาวน์โหลดจากหน้าคู่มือผู้ใช้)
  2. เมื่อดาวน์โหลดเสร็จ คลิกขวาที่ `bpp-vms-installer.zip` > **Extract All (แตกไฟล์ทั้งหมด)** > เลือกแตกไฟล์ลงที่ไดรฟ์ **`D:\`**
  3. ระบบจะสร้างโฟลเดอร์ `D:\BPP-VMS\` ที่มีโครงสร้างถูกต้องสมบูรณ์ทันที

- **วิธีที่ 2 (ออฟไลน์ 100% — ก๊อปปี้ผ่าน Flash Drive จากเครื่องแม่):**
  1. ที่เครื่องแม่ ให้ดับเบิลคลิกไฟล์ **`Export_Installer_Package.bat`**
  2. ระบบจะสร้างไฟล์ `bpp-vms-installer.zip` (ขนาดประมาณ 86.9 MB)
  3. นำไฟล์ใส่ Flash Drive ไปเสียบที่เครื่องใหม่ แล้วแตกไฟล์ลงที่ไดรฟ์ **`D:\`**

**โครงสร้างโฟลเดอร์ที่ได้จะถูกต้องสมบูรณ์แบบ 100% ดังนี้:**
```text
D:\BPP-VMS\
├── Setup_New_Machine.bat          <-- [ดับเบิลคลิกไฟล์นี้เพื่อเริ่มติดตั้ง]
├── Update_System.bat             <-- [ดับเบิลคลิกไฟล์นี้เมื่อต้องการอัปเดต]
├── Export_Installer_Package.bat  <-- [ส่งออกชุดติดตั้งสำหรับเครื่องอื่น]
├── Export_System.bat             <-- [ส่งออกข้อมูลจากเครื่องเก่า]
├── Import_System.bat             <-- [นำเข้าข้อมูลสู่เครื่องใหม่]
├── git_and_fresh_install_manual.html
└── frigate-nvr\
```

#### 🔹 สเต็ปที่ 3: ดับเบิลคลิกไฟล์ `Setup_New_Machine.bat`
1. คลิกขวาที่ **`Setup_New_Machine.bat`** > เลือก **Run as administrator** (หรือดับเบิลคลิก ระบบจะขอยกระดับสิทธิ์อัตโนมัติ)
2. หน้าต่างสีดำจะเริ่มทำงานโดยอัตโนมัติ:
   - ตรวจสอบ Docker Engine
   - สุ่มสร้างรหัสความปลอดภัย 64-char Hex ลงในไฟล์ `.env` ครบทุกตัว
   - สร้างใบรับรอง SSL HTTPS
   - เริ่มการทำงานของบริการ Docker ทั้งหมด
3. **ตั้งรหัสผ่าน Admin:**
   - เมื่อถึงขั้นตอนสุดท้าย ระบบจะถาม:
     ```text
     ชื่อบัญชี (Username): admin
     กรุณาตั้งรหัสผ่านสำหรับ admin (ความยาวตั้งแต่ 8 ตัวอักษรขึ้นไป)
     * หากต้องการใช้รหัสผ่านชั่วคราวเริ่มต้น ให้กดปุ่ม [Enter] ได้ทันที *
       (รหัสผ่านเริ่มต้นคือ: ChangeMeAdmin123!)
     ```
   - **ท่านสามารถกดปุ่ม `[Enter]` ทันที** เพื่อใช้รหัสผ่าน `ChangeMeAdmin123!` หรือพิมพ์รหัสผ่านที่ท่านต้องการ
4. **เสร็จสิ้น!** เบราว์เซอร์จะเปิดหน้าเว็บ `https://localhost` ขึ้นมาให้โดยอัตโนมัติ
   *(ข้อมูล Username และ Password จะถูกบันทึกสำรองไว้ในไฟล์ `D:\BPP-VMS\Admin_Login_Info.txt` ให้ท่านเปิดดูได้ตลอดเวลา)*

## ตอนที่ 2: ขั้นตอนการอัปเดตระบบเป็นเวอร์ชันล่าสุด

เมื่อโปรเจกต์หลักมีการอัปเดตฟีเจอร์หรือแก้ไขปรับปรุงใหม่ ท่านสามารถอัปเดตเครื่องที่ติดตั้งไปแล้วได้ง่ายๆ ตามรูปแบบของเครื่อง:

### 🔹 รูปแบบที่ 1: เครื่องหลักที่มี Git (Online Git Machine)
1. ไปที่โฟลเดอร์ `D:\BPP-VMS`
2. ดับเบิลคลิกไฟล์ **`Update_System.bat`**
3. ระบบจะดึงโค้ดล่าสุดจาก GitHub (`git pull origin main`) และสั่งเริ่มบริการใหม่ (`docker compose up -d`) ให้อัตโนมัติ
4. ข้อมูลผู้ใช้, รหัสผ่าน, ฐานข้อมูล, และภาพบันทึกวิดีโอย้อนหลังเดิมจะ**คงอยู่ครบ 100%**
*(หมายเหตุ: หากต้องการส่งต่ออัปเดตนี้ให้เครื่องลูกข่าย ให้ดับเบิลคลิก `Export_Installer_Package.bat` 1 ครั้ง เพื่อสร้างไฟล์ ZIP ใหม่ส่งต่อ)*

### 🔹 รูปแบบที่ 2: เครื่องลูกข่ายหน้างานที่ลงผ่าน ZIP (Zero-GitHub Offline Machine)
1. **รับไฟล์อัปเดตใหม่:** ดาวน์โหลดไฟล์ `bpp-vms-installer.zip` ล่าสุดจากเครื่องแม่ (ผ่านหน้าเว็บ `https://vms.local/downloads/bpp-vms-installer.zip` หรือก๊อปปี้ผ่าน USB Flash Drive)
2. **แตกไฟล์ทับที่เดิม:** แตกไฟล์ (Extract) ลงที่ไดรฟ์ `D:\` ทับโฟลเดอร์ `D:\BPP-VMS` เดิมได้ทันที
   - **ปลอดภัย 100%:** ไฟล์ ZIP ไม่มี `.env`, ไม่มีฐานข้อมูล `*.db`, และไม่มีโฟลเดอร์วิดีโอ `storage/` ดังนั้นข้อมูลบัญชีผู้ใช้และการตั้งค่าเดิมจะไม่ถูกลบหรือสูญหายแน่นอน
3. **เริ่มระบบใหม่:** ดับเบิลคลิกไฟล์ **`Update_System.bat`** (หรือ `Setup_New_Machine.bat`) 1 ครั้ง ระบบจะโหลดโค้ดเวอร์ชันใหม่เข้า Docker และพร้อมใช้งานทันทีในไม่กี่วินาที!

## ตอนที่ 3: การย้ายข้อมูลและรหัสผ่านจากเครื่องเก่า

หากท่านมีเครื่องเดิมที่ใช้งานอยู่แล้ว และต้องการย้ายกล้อง, ผู้ใช้ทุกคน, และการตั้งค่ามาที่เครื่องใหม่โดยไม่ต้องเริ่มนับหนึ่งใหม่:

1. **ที่เครื่องเก่า:**
   - ดับเบิลคลิกไฟล์ **`Export_System.bat`**
   - ตั้งรหัสผ่านสำหรับล็อกไฟล์สำรอง 1 ชุด
   - ระบบจะสร้างไฟล์ `D:\BPP-VMS-FullBackup.tar.enc` ให้ท่านก๊อปปี้ใส่ Flash Drive
2. **ที่เครื่องใหม่:**
   - วางไฟล์ `BPP-VMS-FullBackup.tar.enc` ไว้ที่ไดรฟ์ `D:\`
   - ดับเบิลคลิกไฟล์ **`Import_System.bat`**
   - กรอกรหัสผ่านที่ตั้งไว้ตอน Export
   - ข้อมูลบัญชีผู้ใช้และการตั้งค่าทั้งหมดจะถูกกู้คืนกลับมาครบถ้วน 100%!

## 5. คำถามที่พบบ่อยและการแก้ปัญหา

### Q1: เปิดเว็บ `https://localhost` แล้วเบราว์เซอร์แจ้งว่า "Your connection is not private"?
- **คำตอบ:** เป็นเรื่องปกติของการใช้ใบรับรอง Self-Signed SSL ภายในองค์กร ให้คลิกปุ่ม **"Advanced" (ขั้นสูง)** แล้วคลิก **"Proceed to localhost (unsafe)"** เพื่อเข้าใช้งานตามปกติ

### Q2: ดับเบิลคลิก `Setup_New_Machine.bat` แล้วขึ้นเตือน "ไม่พบการทำงานของ Docker Desktop"?
- **คำตอบ:** ให้เปิดโปรแกรม Docker Desktop ที่เครื่องของท่านก่อน รอให้สถานะเป็นสีเขียว แล้วกดปุ่ม Enter ที่หน้าต่างสีดำ สคริปต์จะทำงานต่อให้อัตโนมัติ

### Q3: รหัสผ่านเข้าใช้งานครั้งแรกคืออะไร?
- **Username:** `admin`
- **Password:** `ChangeMeAdmin123!` *(หรือรหัสผ่านที่ท่านพิมพ์ตั้งไว้ตอนรันตัวติดตั้ง โดยสามารถเปิดดูในไฟล์ `D:\BPP-VMS\Admin_Login_Info.txt` ได้เสมอ)*
