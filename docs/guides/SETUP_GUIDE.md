# 📘 คู่มือการย้ายระบบและติดตั้ง BPP-VMS บนเครื่องใหม่ (Complete Setup & Migration Guide)

คู่มือนี้อธิบายขั้นตอนการนำโปรเจกต์ **BPP-VMS** ไปติดตั้งบนเครื่องใหม่อย่างละเอียด โดยแบ่งออกเป็น **2 ทางเลือกหลัก** ตามความต้องการใช้งานของคุณ

---

## 🧭 เลือกทางเลือกที่เหมาะกับคุณ

| ทางเลือก | วิธีการ | ต้องใช้ Git ไหม? | เหมาะสำหรับ | สิ่งที่ได้บนเครื่องใหม่ |
|---|---|---|---|---|
| **ทางเลือก A** | Clone จาก **GitHub** | **ต้องใช้** | ต้องการโค้ดล่าสุดไปพัฒนาต่อ หรืออยากได้ระบบแบบตั้งต้นใหม่ (Clean Install) | ได้โค้ดล่าสุด ระบบตั้งต้น สะอาด ปลอดภัย |
| **ทางเลือก B** | ย้ายด้วยไฟล์ **Full Backup** (`.tar.enc`) | **ไม่ต้องใช้** | ต้องการย้ายระบบ กล้อง ผู้ใช้งาน และข้อมูลเดิมจากเครื่องนี้ไปรันต่อทันที | ได้ทุกอย่างเหมือนเครื่องเดิม 100% (รวม Docker Images และข้อมูลผู้ใช้เดิม) |

---

## 🟢 ทางเลือก A: ติดตั้งใหม่จาก GitHub (สำหรับรันใหม่ / พัฒนาต่อ)

### สิ่งที่ต้องเตรียม (Prerequisites)
1. **Git**: สำหรับดึงโค้ด ([ดาวน์โหลด Git](https://git-scm.com/))
2. **Docker Desktop**: สำหรับรันระบบ ([ดาวน์โหลด Docker Desktop](https://www.docker.com/products/docker-desktop/))
   - *คำแนะนำ:* ต้องเปิดใช้งาน **WSL 2-based engine** ในการตั้งค่าของ Docker Desktop

---

### ขั้นตอนการดำเนินการ (ทางเลือก A)

#### 1. ดึงโค้ดมาจาก GitHub (Clone Project)
เปิด **Command Prompt** หรือ **PowerShell** บนเครื่องใหม่ แล้วรันคำสั่ง:
```bash
# Clone โปรเจกต์ลงเครื่อง
git clone https://github.com/itbpp215-creater/VMS-215.git

# เข้าไปยังโฟลเดอร์โปรเจกต์
cd VMS-215/frigate-nvr
```

#### 2. สั่งเริ่มระบบด้วย Docker
```bash
# Build และเปิด Container ทั้งหมด
docker compose build
docker compose up -d
```
*(รอระบบดาวน์โหลดและ Build Container จนเสร็จ)*

#### 3. สร้างบัญชีผู้ดูแลระบบคนแรก (Bootstrap Admin)
```bash
docker compose run --rm auth-service python manage.py bootstrap-admin admin --output-file /data/admin-credential.once
```
- ระบบจะสร้างผู้ใช้ชื่อ `admin` และ **แสดงรหัสผ่านเริ่มต้นบนหน้าจอ Terminal**
- ให้คัดลอกรหัสผ่านนั้นไว้ใช้ล็อกอินครั้งแรก

#### 4. เข้าใช้งานหน้าเว็บ
- เปิดเบราว์เซอร์แล้วเข้าไปที่: **`https://localhost/`**
- กรอก Username (`admin`) และรหัสผ่านที่ได้จากข้อ 3
- เมื่อเข้าสู่ระบบสำเร็จ สามารถไปเปลี่ยนรหัสผ่านใหม่ได้ที่หน้าจัดการผู้ใช้งาน

## 🔵 ทางเลือก B: ย้ายระบบด้วยไฟล์ Full Backup (ไม่ต้องใช้ Git)

ทางเลือกนี้ **ไม่ต้องใช้ Git หรืออินเทอร์เน็ตในการโหลดโค้ดใหม่** เพราะไฟล์สำรองรวมทุกอย่างไว้ครบหมดแล้ว

### สิ่งที่ต้องเตรียม (Prerequisites)
1. **Docker Desktop**: ติดตั้งบนเครื่องใหม่ ([ดาวน์โหลด Docker Desktop](https://www.docker.com/products/docker-desktop/))
2. **ไฟล์สำรอง**: `D:\BPP-VMS-FullBackup.tar.enc` (ที่แพ็กไว้เรียบร้อยแล้ว)
3. **ไฟล์สคริปต์นำเข้า**: `Import_System.bat` (จากโฟลเดอร์โปรเจกต์เดิม)

---

### ขั้นตอนการดำเนินการ (ทางเลือก B)

#### 1. ก๊อปปี้ไฟล์ไปไว้ที่เครื่องใหม่
- นำไฟล์ `BPP-VMS-FullBackup.tar.enc` ไปวางไว้ที่ไดรฟ์ **`D:\`** ของเครื่องใหม่ (เช่น `D:\BPP-VMS-FullBackup.tar.enc`)
- นำไฟล์ **`Import_System.bat`** ไปวางไว้ในเครื่องใหม่

#### 2. รันสคริปต์นำเข้าระบบ
- คลิกขวาที่ไฟล์ **`Import_System.bat`** ➔ เลือก **Run as administrator** (รันในฐานะผู้ดูแลระบบ)
- สคริปต์จะทำการ:
  - แตกไฟล์ระบบทั้งหมดลงเครื่องใหม่
  - โหลด Docker Images ที่แพ็กไว้เข้าสู่ระบบอัตโนมัติ
  - เปิดการทำงานของทุกบริการให้อัตโนมัติ

#### 3. เข้าใช้งานระบบ
- เปิดเบราว์เซอร์แล้วเข้าไปที่: **`https://localhost/`**
- **ล็อกอินด้วย Username และ Password เดิม** จากเครื่องเก่าได้ทันที ข้อมูลผู้ใช้และสิทธิ์ทั้งหมดจะเหมือนเดิม 100%

## 💻 การทำงานและอัปเดตโค้ดในอนาคต ( Git Workflow )

เมื่อมีการแก้ไขหรือพัฒนาโค้ดเพิ่มเติมในอนาคต ให้ใช้คำสั่ง Git เหล่านี้:

```bash
# 1. ดึงโค้ดล่าสุดก่อนเริ่มงานเสมอ
git pull origin main

# 2. ตรวจสอบไฟล์ที่แก้ไข
git status

# 3. บันทึกและส่งโค้ดกลับขึ้น GitHub
git add .
git commit -m "คำอธิบายสิ่งที่แก้ไขหรือเพิ่มฟีเจอร์ใหม่"
git push
```

## 🛠️ การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

- **หน้าเว็บไม่เปลี่ยนตามโค้ดที่แก้ไข:** ให้กด `Ctrl + F5` ในเบราว์เซอร์เพื่อ Hard Refresh
- **ตรวจสอบสถานะระบบทั้งหมด:**
  ```bash
  docker compose ps
  ```
- **ดู Log การทำงานเพื่อวิเคราะห์ข้อผิดพลาด:**
  ```bash
  docker compose logs -f <ชื่อบริการ เช่น auth-service หรือ frigate-nvr>
  ```
- **สั่ง Restart ระบบใหม่ทั้งหมด:**
  ```bash
  docker compose restart
  ```
