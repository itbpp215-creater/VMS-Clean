# คู่มือการติดตั้งระบบสำหรับเครื่องใหม่ (Clean Standalone Installation Guide)
**สำหรับนำระบบ VMS ไปติดตั้งยังเครื่องภายนอก / หน่วยงานอื่น โดยไม่มีข้อมูลของ ตชด.215**

---

## 🎯 ภาพรวมและหลักการ

ระบบชุดนี้เป็น **Clean Standalone Framework** ที่ตัดข้อมูลการตั้งค่าเฉพาะของ กองร้อย ตชด.215 ออกทั้งหมด 100%:
- ❌ **ไม่มี** ลิงก์สตรีม, IP, หรือรหัสผ่านกล้องของ ตชด.215
- ❌ **ไม่มี** ข้อมูลเชื่อมต่อ Synology NAS ของ ตชด.215
- ❌ **ไม่มี** โทเค็น Telegram Bot และ Chat ID ส่วนตัว
- ❌ **ไม่มี** Google Gemini API Key เดิม
- ❌ **ไม่มี** บัญชีเฝ้าระวังป้ายทะเบียนต้องสงสัย (Suspect Watchlist)
- ❌ **ไม่มี** โทเค็น Cloudflare Tunnel / Tailscale ส่วนตัว

ผู้ดูแลระบบประจำเครื่องใหม่ สามารถตั้งค่าตามคู่มือนี้เพื่อเริ่มใช้งานระบบของตนเองได้อย่างปลอดภัยและสมบูรณ์

---

## 📋 สิ่งที่ต้องจัดเตรียม (Checklist 5 รายการสำคัญ)

| รายการ | ความจำเป็น | เอามาจากไหน | เอามาใส่ตรงไหน |
| :--- | :---: | :--- | :--- |
| **1. บัญชี Superadmin** | **จำเป็น** | ตั้งรหัสผ่านขึ้นมาใหม่เองตอนติดตั้ง | หน้าต่างตอนรัน `Setup_New_Machine.bat` |
| **2. กล้องวงจรปิด (RTSP)** | **จำเป็น** | IP Camera / DVR / NVR ในเครือข่ายของท่าน | `frigate-nvr/config/config.yml` หรือเมนูจัดการกล้องบนเว็บ |
| **3. Google Gemini API Key** | เสริม (AI Bot) | ขอฟรีได้ที่ Google AI Studio | `frigate-nvr/.env` หรือกรอกในตัวติดตั้ง |
| **4. Telegram Bot Token** | เสริม (แจ้งเตือน) | สร้างฟรีผ่านแอป Telegram (`@BotFather`) | `frigate-nvr/.env` หรือรัน `Setup_Telegram_Bot.bat` |
| **5. NAS Storage** | เสริม (สำรองไฟล์) | Synology หรือ File Server ในหน่วยงาน | `frigate-nvr/.env` หรือรัน `Setup_NAS_Storage.bat` |

*(หมายเหตุ: รายการที่ 3-5 หากยังไม่มี สามารถกด Enter ข้ามตอนติดตั้งได้ทันที ระบบจะเปิดทำงานหน้าเว็บและระบบตรวจจับวัตถุได้ตามปกติ 100%)*

## 🛠️ ขั้นตอนการเตรียมข้อมูลและวิธีใส่ค่าโดยละเอียด

### 1. บัญชีผู้ดูแลระบบ (Superadmin Account)
* **คืออะไร**: บัญชีสำหรับเข้าสู่ระบบหน้าเว็บหลัก (`https://localhost`) เพื่อดูภาพสด ค้นหาป้ายทะเบียน และบริหารจัดการ
* **วิธีทำ**:
  1. เมื่อรันไฟล์ `Setup_New_Machine.bat` ระบบจะหยุดถามให้ตั้งรหัสผ่านสำหรับชื่อผู้ใช้ `admin`
  2. ใส่รหัสผ่านความยาวตั้งแต่ 8 ตัวอักษรขึ้นไปตามที่ต้องการ
  3. ระบบจะบันทึกช่วยจำไว้ที่ไฟล์ `Admin_Login_Info.txt` ที่หน้าหลักอัตโนมัติ

---

### 2. ลิงก์สตรีมกล้องวงจรปิด (Camera RTSP Streams)
* **คืออะไร**: ลิงก์ดึงภาพวิดีโอจากกล้อง IP Camera หรือเครื่องบันทึก DVR/NVR ในพื้นที่ของท่าน
* **เอามาจากไหน**:
  - ดูคู่มือหรือหน้าเว็บตั้งค่าของกล้องแต่ละยี่ห้อ (ปกติพอร์ต RTSP คือ `554`)
  - รูปแบบมาตรฐานของยี่ห้อยอดนิยม:
    - **Hikvision / Hilook**: `rtsp://<user>:<pass>@<ip-กล้อง>:554/Streaming/Channels/101`
    - **Dahua / Imou**: `rtsp://<user>:<pass>@<ip-กล้อง>:554/cam/realmonitor?channel=1&subtype=0`
    - **Uniview (UNV)**: `rtsp://<user>:<pass>@<ip-กล้อง>:554/unicast/c1/s0/live`
    - **กล้องทั่วไป (ONVIF)**: `rtsp://<user>:<pass>@<ip-กล้อง>:554/live/ch0`
* **เอามาใส่ตรงไหน**:
  - เปิดไฟล์ `D:\BPP-VMS\frigate-nvr\config\config.yml` ด้วย Notepad
  - มองหาหัวข้อ `go2rtc:` และ `cameras:` ใส่ชื่อกล้องและ RTSP URL ตามตัวอย่าง:
  ```yaml
  go2rtc:
    streams:
      gate_camera:
        - rtsp://admin:Password123@192.168.1.101:554/Streaming/Channels/101

  cameras:
    gate_camera:
      ffmpeg:
        inputs:
          - path: rtsp://127.0.0.1:8554/gate_camera
            roles:
              - detect
              - record
      detect:
        enabled: true
      record:
        enabled: true
  ```
  - *หรือเพิ่มและแก้ไขผ่านหน้า Dashboard เมนู "ตั้งค่ากล้อง" บนเว็บเบราว์เซอร์*

---

### 3. Google Gemini API Key (สมองกล AI ประจำระบบ)
* **คืออะไร**: คีย์เชื่อมต่อปัญญาประดิษฐ์ Google Gemini 2.5 สำหรับฟังก์ชัน:
  - แชทบอทตอบคำถามและสืบค้นข้อมูล
  - วิเคราะห์สรุปแฟ้มประวัติบุคคล (Dossier OCR Narrative)
  - วิเคราะห์ความเชื่อมโยงแผนผัง IBM i2
* **เอามาจากไหน (วิธีขอฟรี)**:
  1. เข้าเว็บไซต์ Google AI Studio: [https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
  2. ล็อกอินด้วยบัญชี Gmail ของท่าน
  3. คลิกปุ่มสีฟ้า **"Create API key"**
  4. เลือกโปรเจกต์ หรือกด Create key in new project
  5. ก๊อปปี้คีย์ที่ได้ (จะขึ้นต้นด้วย `AIzaSy...`)
* **เอามาใส่ตรงไหน**:
  - **วิธีที่ 1**: วางตอนรัน `Setup_New_Machine.bat` ในขั้นตอนติดตั้ง n8n
  - **วิธีที่ 2**: ใส่ในไฟล์ `D:\BPP-VMS\frigate-nvr\.env` ที่บรรทัด:
    ```env
    GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxx
    ```

---

### 4. Telegram Bot Token & Chat ID (ระบบแจ้งเตือนผ่านมือถือ)
* **คืออะไร**: การผูกบอทเพื่อส่งภาพถ่ายและข้อความแจ้งเตือนด่วนเข้า Telegram เมื่อตรวจพบป้ายทะเบียนเฝ้าระวัง
* **เอามาจากไหน (วิธีขอฟรี)**:
  1. **สร้าง Bot Token**:
     - เปิดแอป Telegram ค้นหา `@BotFather` (มีติ๊กถูกสีฟ้า)
     - ส่งข้อความ `/newbot`
     - ตั้งชื่อบอท (เช่น `MyStation Alert Bot`)
     - ตั้ง Username ของบอทลงท้ายด้วย `_bot` (เช่น `mystation_alert_bot`)
     - BotFather จะให้ **HTTP API Token** เช่น `7890123456:AAFd4xxxxxxxxxxxxxxxxx`
  2. **หา Chat ID ของท่าน**:
     - ค้นหาบอท `@userinfobot` ใน Telegram แล้วกด Start
     - บอทจะแจ้งหมายเลข `Id:` เช่น `123456789`
     - *(ถ้าต้องการแจ้งเตือนลงกลุ่ม: ดึงบอทเข้ากลุ่ม พิมพ์ `@getidsbot` เพื่อดู Chat ID ของกลุ่ม ซึ่งจะขึ้นต้นด้วย `-100...`)*
* **เอามาใส่ตรงไหน**:
  - **วิธีที่ 1**: ดับเบิลคลิกไฟล์ `Setup_Telegram_Bot.bat` ที่หน้าแรก แล้ววาง Token
  - **วิธีที่ 2**: ใส่ในไฟล์ `D:\BPP-VMS\frigate-nvr\.env` ที่บรรทัด:
    ```env
    TELEGRAM_BOT_TOKEN=7890123456:AAFd4xxxxxxxxxxxxxxxxx
    TELEGRAM_CHAT_ID=123456789
    ```

---

### 5. NAS Storage (พื้นที่สำรองข้อมูลเครือข่าย - ไม่บังคับ)
* **คืออะไร**: การส่งไฟล์วิดีโอย้อนหลังและภาพตัดป้ายทะเบียน LPR ไปเก็บไว้ที่ Synology NAS หรือ Server กลาง
* **เอามาจากไหน**:
  - สอบถาม IP และ Folder แชร์จากผู้ดูแลเครือข่ายของหน่วยงาน เช่น IP `192.168.1.200` โฟลเดอร์ `vms_storage`
* **เอามาใส่ตรงไหน**:
  - **วิธีที่ 1**: ดับเบิลคลิกไฟล์ `Setup_NAS_Storage.bat` ที่หน้าแรก แล้วกรอกค่าตามที่ระบบถาม
  - **วิธีที่ 2**: ใส่ในไฟล์ `D:\BPP-VMS\frigate-nvr\.env` ที่บรรทัด:
    ```env
    NAS_HOST=192.168.1.200
    NAS_SHARE=vms_storage
    NAS_USER=admin
    NAS_PASS=NasPassword123
    ```
  - *(หากไม่มี NAS ไม่ต้องใส่ ระบบจะเก็บข้อมูลลงในไดรฟ์ D:\ ของคอมพิวเตอร์เครื่องนั้นโดยอัตโนมัติ)*

## 🚀 ขั้นตอนการเริ่มเปิดระบบบนเครื่องใหม่

1. **เตรียมเครื่องปลายทาง**:
   - ติดตั้ง Docker Desktop บนเครื่องปลายทางและเปิดโปรแกรมให้พร้อม
2. **รันการติดตั้ง**:
   - ดับเบิลคลิกที่ไฟล์ `Setup_New_Machine.bat`
   - ทำตามคำแนะนำบนหน้าจอ (กำหนดรหัสผ่าน Superadmin และวางคีย์ที่เตรียมไว้)
3. **เข้าใช้งาน**:
   - เปิดเว็บเบราว์เซอร์ไปที่: `https://localhost`
   - ล็อกอินด้วยชื่อผู้ใช้ `admin` และรหัสผ่านที่ตั้งไว้
4. **การอัปเดตระบบในอนาคต**:
   - หากติดตั้งผ่าน Git: รันคำสั่ง `git pull` หรือดับเบิลคลิก `Update_System.bat`
   - การตั้งค่ากล้อง รหัสผ่าน และบอทของท่านจะยังคงอยู่ครบถ้วน ไม่สูญหาย 100%
