📹 BPP-VMS Clean Installation Guide

คู่มือเตรียมข้อมูลและตั้งค่าระบบสำหรับเครื่องใหม่ (Zero-BPP215 Leak)

🛡️ ปลอดภัย 100% — ปราศจากข้อมูลความลับของ ตชด.215

📋 สิ่งที่ต้องจัดเตรียมก่อนเริ่มติดตั้ง (Quick Checklist)

ระบบนี้เปิดทำงานได้ทันทีแม้ยังไม่มีคีย์เสริม โดยคุณสามารถนำคีย์ของหน่วยงานตนเองมาใส่ตามหัวข้อด้านล่างนี้:

ลำดับ รายการ ความสำคัญ เอามาจากไหน นำไปใส่ตรงไหน
1 Superadmin Password จำเป็น กำหนดขึ้นใหม่เอง หน้าต่างตอนรัน Setup_New_Machine.bat
2 กล้องวงจรปิด (RTSP) จำเป็น กล้อง IP / NVR ในเครือข่ายของท่าน config/config.yml หรือหน้าเว็บเมนูจัดการกล้อง
3 Google Gemini API Key เสริม (AI) Google AI Studio (สมัครฟรี) frigate-nvr/.env หรือกรอกตอนติดตั้ง
4 Telegram Bot Token เสริม (แจ้งเตือน) แอป Telegram ผ่าน @BotFather Setup_Telegram_Bot.bat หรือใน .env
5 NAS Storage เสริม (สำรองไฟล์) IP Server / Synology ของหน่วยงาน Setup_NAS_Storage.bat หรือใน .env

🔍 รายละเอียดทีละขั้นตอน: เอามาจากไหน และเอาไปใส่ที่ไหน

1. บัญชีผู้ดูแลระบบ (Superadmin Account)

ที่มา: กำหนดเองตอนติดตั้งครั้งแรก ตำแหน่งที่ใส่: หน้าต่าง Command Prompt ขณะรัน Setup_New_Machine.bat
  1. เมื่อดับเบิลคลิกไฟล์ Setup_New_Machine.bat ตัวช่วยติดตั้งจะหยุดถามรหัสผ่านสำหรับบัญชี admin
  2. พิมพ์รหัสผ่านที่ต้องการ (ความยาวตั้งแต่ 8 ตัวอักษรขึ้นไป) แล้วกด Enter
  3. ระบบจะสร้างไฟล์ช่วยจำชื่อ Admin_Login_Info.txt ไว้ที่หน้าหลักของระบบให้อัตโนมัติ

2. สตรีมกล้องวงจรปิด (Camera RTSP Streams)

ที่มา: IP Address, Username, และ Password ของกล้อง IP Camera หรือเครื่องบันทึก DVR/NVR ในจุดตรวจ ตำแหน่งที่ใส่: ไฟล์ frigate-nvr/config/config.yml หรือผ่านหน้า Dashboard "จัดการกล้อง"

ตัวอย่างรูปแบบ RTSP URL ตามยี่ห้อกล้องยอดนิยม:

  • Hikvision / Hilook: rtsp://admin:Password123@192.168.1.101:554/Streaming/Channels/101
  • Dahua / Imou: rtsp://admin:Password123@192.168.1.101:554/cam/realmonitor?channel=1&subtype=0
  • Uniview (UNV): rtsp://admin:Password123@192.168.1.101:554/unicast/c1/s0/live
  • กล้องทั่วไป (ONVIF): rtsp://admin:Password123@192.168.1.101:554/live/ch0

วิธีใส่ลงใน frigate-nvr/config/config.yml:

go2rtc:
  streams:
    cam_gate:
      - rtsp://admin:Pass1234@192.168.1.100:554/Streaming/Channels/101

cameras:
  cam_gate:
    ffmpeg:
      inputs:
        - path: rtsp://127.0.0.1:8554/cam_gate
          roles:
            - detect
            - record
    detect:
      enabled: true
    record:
      enabled: true

3. Google Gemini API Key (สมองกล AI ประจำระบบ)

ที่มา: เว็บไซต์ Google AI Studio (บริการฟรีของ Google) ตำแหน่งที่ใส่: กรอกตอนรัน Setup_New_Machine.bat หรือใส่ใน frigate-nvr/.env
  1. เปิดเบราว์เซอร์แล้วไปที่: 🔗 เปิด Google AI Studio (Get API Key)
  2. ล็อกอินด้วยบัญชี Gmail ของท่าน
  3. กดปุ่มสีน้ำเงิน "Create API key"
  4. คัดลอก (Copy) คีย์ที่ได้รับ (จะขึ้นต้นด้วยตัวอักษร AIzaSy...)
  5. นำมาใส่ในไฟล์ frigate-nvr/.env ตรงบรรทัด: 
    GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

4. Telegram Bot Token & Chat ID (ระบบแจ้งเตือนผ่านมือถือ)

ที่มา: แอป Telegram คุยกับ @BotFather และ @userinfobot ตำแหน่งที่ใส่: รัน Setup_Telegram_Bot.bat หรือใส่ใน frigate-nvr/.env
  1. ขอ Token: เปิด Telegram ค้นหา @BotFather แล้วส่งข้อความ /newbot จากนั้นตั้งชื่อและ Username ให้บอท จะได้ Token เช่น 7123456789:AAH...
  2. หา Chat ID: ค้นหา @userinfobot แล้วกด Start จะได้ตัวเลข ID เช่น 123456789
  3. นำไปใส่โดยดับเบิลคลิก Setup_Telegram_Bot.bat หรือใส่ใน frigate-nvr/.env: 
    TELEGRAM_BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxx
TELEGRAM_CHAT_ID=123456789

5. NAS Storage (พื้นที่สำรองข้อมูลเครือข่าย - ไม่บังคับ)

ที่มา: IP Address และชื่อ Shared Folder ของ NAS ในหน่วยงาน ตำแหน่งที่ใส่: รัน Setup_NAS_Storage.bat หรือใส่ใน frigate-nvr/.env

หากมี Synology NAS ให้ใส่ค่าใน frigate-nvr/.env:

NAS_HOST=192.168.1.200
NAS_SHARE=vms_recordings
NAS_USER=vms_admin
NAS_PASS=NasPassword123

(หากไม่มี ให้เว้นว่างไว้ ระบบจะบันทึกลงในไดรฟ์ D:\ ของเครื่องนั้นเอง)

เมื่อมีเวอร์ชันใหม่ออกมา เพียงรันคำสั่ง git pull หรือดับเบิลคลิก Update_System.bat ระบบจะทำการอัปเดตเฉพาะโค้ดโปรแกรม ส่วนกล้อง บอท รหัสผ่าน และการตั้งค่าของท่านจะคงอยู่ครบ 100% ไม่ถูกเขียนทับแน่นอน
